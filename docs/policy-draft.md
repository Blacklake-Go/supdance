# Supdance 政策草案

以下为待运营者确认的插件专用文案。实际发布时由运营者补充法律实体、联系方式、适用地区、服务提供商、数据留存期限、删除渠道和适用法律。

## 隐私政策

Supdance 处理你选择提交的创作提示、文本附件和创作历史。连接 Supdance 账号时，应用读取用户标识、令牌有效期和授权范围。仅当你选择项目、画布或任务时，服务按相应授权取得上下文。创作文本会转交 Supdance 模型网关用于返回生成结果。确认操作时，服务记录操作内容、报价、状态和回执。审计记录包括时间、散列后的账号标识、操作类型、目标 ID 和结果码。

浏览器会话令牌在服务端加密。工作台保存对话和草稿，用户可以删除自己的对话。删除插件会话不会删除你主动提交到 Supdance 主站的项目、画布和资产。发布者应公布可用于访问、更正、导出及删除数据的渠道，以及对审批、审计、备份及主站资产的留存安排。

## 服务条款

使用者应有权上传或处理提交的素材，遵守适用法律、内容使用规则和知识产权要求。AI 输出可能含有错误，使用者应在制作、分发或发表前审阅。Supdance 在取得用户授权后才可提交项目、画布或媒体操作。可用能力取决于账号权限与服务权益，媒体调用如获启用，确认前显示消耗上限。发布者应补充服务可用性、账号、内容权利、责任和争议解决条款。

## 支持页面

发布时提供可公开访问的帮助入口和工作渠道。处理问题时可请用户提供操作 ID、工具名、发生时间和错误码。支持人员不应索取 OAuth token、密码、内部接口密钥或用户完整对话。
